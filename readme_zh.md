# 工具说明

本项目
**光标镜 (CursorLens)**
是一款基于 Python 标准库 **tkinter** 的输入法检测悬浮窗跟随工具，用于在鼠标指针旁实时显示"当前输入法语言（中文/英文）"与"大小写状态（大写/小写）"。背景是打字时经常需要确认 CapsLock 有没有打开、当前是中文还是英文，通常得低头看任务栏右下角的状态区，视线离开稿面既慢又容易打断思路；本工具把这两个信息搬到光标右下方的一个小胶囊里，实现"手不离键、眼不离字"的确认方式。注意：该文件仅在Windows11下进行测试，不对其他版本的操作系统保障

## 文件夹说明

- `cursorlensv1.0.0.py` – 源代码文件（单文件，仅用标准库，无第三方依赖）
- `cursorlens_config.json` – 配置文件（首次修改设置/退出时自动生成，删除即恢复默认）
- `readme.md` – 英文译文说明文件
- `readme_zh.md` – 本文中文原文说明文件

## 界面示意

悬浮窗示意（`◤` 三角标会朝鼠标所在方向旋转）：

```
 x +50 y +0    ◤    [ 拼 ]   [ 大 ]
 └─偏移标注──┘  └指向鼠标┘ └语言┘ └大小写┘
```

| 元素 | 含义 | 取值 |
| --- | --- | --- |
| 语言徽标 | 当前输入法语言的单字缩写 | 拼 / 五 / 注 / 仓 / 郑 / 中 / EN / 日 / 한 |
| 大小写徽标 | CapsLock 状态（写法随语言切换） | 中文：大 / 小；英文：U / L |
| 三角标 | 指向鼠标指针的方位 | 随偏移方向旋转 |
| 偏移标注 | 当前 x / y 偏移，形如 `x +50 y +0` | -100 ~ +100 |

徽标配色：中文=蓝色、英文=灰蓝；大写/大=红橙、小写/小=灰蓝，颜色本身也能一眼区分状态。

## 项目基础核心原理

三条"读取链"+ 一条"显示链"：

1. **按键触发**：用 `GetAsyncKeyState` 以约 40Hz 轮询若干虚拟键码，把「组合键整体从"未按下"变为"按下"」的那一帧判为一次触发（上升沿），因此按住不放不会反复弹出。
2. **输入法读取（三条线索合并）**：
   - **语言 ID**：`GetKeyboardLayout(前台窗口线程)` 取键盘布局句柄 HKL，低 16 位即语言 ID（0x0804 系 = 中文）；
   - **中文/英文模式（关键，且必须跨进程）**：先试 `ImmGetContext` + `ImmGetConversionStatus`（`IME_CMODE_NATIVE` 位 = 中文模式）；现代程序（Chrome/Edge/Electron/UWP 等）走 TSF，`ImmGetContext` 对它们的窗口返回 NULL，此时改用 `ImmGetDefaultIMEWnd` + `SendMessageTimeout(WM_IME_CONTROL, IMC_GETCONVERSIONMODE)` 读同一份"本机模式"标志位——这条路径跨进程可用，是"在其他程序里也能识别中英文"的关键；
   - **输入法名字**：`ImmGetDescription` / `ImmGetIMEFileName` → 注册表 `Keyboard Layouts\<KLID>`（传统/第三方输入法）→ 注册表 `CTF\TIP` 里该语言**已启用**的 TSF 输入法（Windows 11 的微软拼音/微软五笔不注册 KLID，只能从这里拿名字，`Display Description` 还是 `@...dll,-5300` 这样的间接字符串，需用 `SHLoadIndirectString` 解析），再按关键字映射成 拼 / 五 / 注 / 仓。

   同时程序会忽略**自己**的窗口作为"前台窗口"（记住最近一个非本程序的前台窗口），否则一旦自己的浮窗/设置窗成为前台，就会读到本进程的输入法上下文，出现"只有设置界面里识别正常"的假象。
3. **大小写读取**：`GetKeyState(VK_CAPITAL)` 的最低位就是 CapsLock 开关状态。
4. **定位与显示**：`GetCursorPos` 取鼠标坐标，加可调偏移得到悬浮窗左上角坐标，必要时钳制在虚拟屏幕矩形内；窗口用 `overrideredirect` 去掉标题栏、`-transparentcolor` 抠掉底色、`WS_EX_TRANSPARENT` 实现鼠标穿透。

**举例：**
按 Ctrl+Space 切到微软拼音，再按一次 CapsLock：

- Ctrl+Space 触发 → 读到语言 ID 0x0804、本机模式 = True、描述含"微软拼音" → 语言徽标显示 `拼`，大小写徽标此时显示 `小`；
- CapsLock 触发 → CapsLock 状态翻转 → 大小写徽标变 `大`，语言徽标仍是 `拼`；
- 再按 Ctrl+Space 切到英文 → 语言徽标变 `EN`，大小写徽标同步改成英文写法 `U` / `L`。

## 具体核心原理流程

①按键轮询 → ②触发判定（设置快捷键优先，其次触发键）→ ③读取输入法状态 → ④读取 CapsLock → ⑤按语言决定大小写写法 → ⑥渲染悬浮窗 → ⑦定位跟随与超时隐藏。

## 使用说明

- 运行 `cursorlensv1.0.0.py` 即可：命令行执行 `python cursorlensv1.0.0.py`；若不想保留控制台窗口，可用 `pythonw cursorlensv1.0.0.py` 或直接双击（关联 pythonw 时）。启动时悬浮窗会先在鼠标旁显示 2 秒，作为"程序已经跑起来"的提示。

- 默认触发键为 `CapsLock` 与 `Ctrl+Space`，按下即在鼠标右下方（默认 x +20 / y +20）弹出指示窗，**默认显示 1 秒**后自动隐藏；显示期间持续跟随鼠标移动。

- 显示方式可在设置里切换（默认"触发显示"）：

  - **触发显示（默认）**：按下触发键后显示一段时间再自动隐藏，时长可选 **0.3 / 0.5 / 1 / 2 / 4 秒**（默认 1 秒）。
  - **保持显示**：按一次触发键显示、再按一次隐藏，不会自动消失（适合长时间盯着输入状态）。
  - **常显**：一直显示并跟随鼠标。

- 默认设置快捷键为 **三连组合键** `Ctrl+Alt+C`，按下即打开选项卡式设置窗口：

  - **触发与显示**：勾选候选触发组合键（**最多 2 个**）、显示方式（触发显示 / 保持显示 / 常显）、触发后显示时长（0.3 / 0.5 / 1 / 2 / 4 秒）、录制新的设置快捷键。
  - **显示位置**：x / y 偏移滑块（-100 ~ +100 像素）、一键归零、是否限制在屏幕范围内。打开设置窗口期间指示窗会实时跟随鼠标，可以边看边调。
  - **样式 / 其他**：缩放、不透明度、是否显示偏移标注 / 三角标、鼠标穿透开关、**显示诊断信息**、语言识别兜底（自动 / 固定 拼 / 五 / 中 / EN）、界面语言（中文/English）、**诊断信息**按钮（复制识别数据）、恢复默认、退出程序。

- 设置窗口中的改动**即时生效**并写入 `cursorlens_config.json`，无需"应用"按钮；下次启动自动读回。

- 退出程序：打开设置窗口 → 点击"退出程序"（后台运行时没有任务栏图标，只能由该快捷键唤出设置窗口）。

## 其他事项&边界与调参

- ① **平台限制**：只有 Windows 能读到真实的输入法与按键状态（依赖 `user32.dll` / `imm32.dll`）。其他平台导入不报错，但状态为空、不显示内容，可在源码里替换 `WinAPI` 实现来适配别的系统。

- ② 中英文识别走两条路：`ImmGetContext`（同进程/传统程序最准）→ `WM_IME_CONTROL`（跨进程，现代程序可用）。两者都读不到时（例如以管理员权限运行的前台窗口、独占全屏游戏被 UIPI 拦截），退化为按语言 ID 判断（中文布局→中/拼，其他→`EN`）；此时可在 **显示诊断信息** 打开后按触发键查看 `source` 字段确认原因。

- ③ 拼音/五笔的判断顺序是：描述/文件名/键盘布局名 → 该语言下**唯一启用**的 TSF 输入法名。若同一语言里启用了多个输入法（例如同时启用微软拼音与微软五笔），无法跨进程唯一确定是哪一个，此时显示通用的 `中`，可在 **样式 / 其他 → 语言识别** 里固定为 `拼` / `五` / `中` / `EN`。

- ④ **识别不对时的排查步骤**：打开设置 → 样式 / 其他 → 勾选「显示诊断信息」→ 关闭设置窗口 → 切到出问题的程序里按下触发键，浮窗底部会多出一行 `hkl / n= / o= / source / ime=` 原始数据；点「诊断信息」按钮可复制完整报告。把这行数据发出来就能定位是"读不到模式"还是"名字没识别"。

- ⑤ 触发键候选写在源码顶部的 `TRIGGER_CANDIDATES` 列表里，直接增删即可扩展；每个候选是 `ctrl+space` 这样的组合字符串，键名支持 `ctrl` / `shift` / `alt` / `win` / `space` / `capslock` / `f1`~`f24` / `a`~`z` / `num0`~`num9` / `` ` `` `-` `=` `[` `]` `\` `;` `'` `,` `.` `/`。

- ⑥ 设置快捷键要求"三连组合键"：录制时**同时按下 3 个及以上按键**即可完成，按 `Esc` 取消；若录制的组合与已选触发键存在包含关系（互为子集），程序会提示可能互相干扰。

- ⑦ 偏移的 ±100 像素是需求约定的调节区间，配置文件里写入超范围的值会被校验夹回边界；默认 `x +20 y +20` 即"光标右下方"。

- ⑧ 指示窗默认开启**鼠标穿透**：它不会抢走任何点击、也不会抢焦点，代价是无法用鼠标右键点开——请用设置快捷键。关闭该开关后建议把偏移调大一些，否则浮窗可能挡住你想点的地方。

- ⑨ 性能：按键轮询周期 25ms（约 40Hz），常显模式下状态刷新 180ms 一次；只有"徽标内容变化"或"配置变化"时才重绘画面，跟随鼠标时只更新窗口位置，因此空载开销极低。

- ⑩ 若 CapsLock 被系统/输入法映射成了"切换中英文"（部分用户自定义），则 CapsLock 触发与语言切换会同时发生，属于预期行为，此时徽标会一起变化以便你确认结果。

- ⑪ 浮窗采用的是"透明色键"抠底（不是逐像素 Alpha 蒙版），所以底板是硬边缘圆角；若想要柔和的阴影/半透明圆角，可改用 Pillow 预渲染 PNG 作为底板图。

## 配置文件字段说明（`cursorlens_config.json`）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `triggers` | `["capslock","ctrl+space"]` | 触发键组合，最多 2 个 |
| `settings_hotkey` | `"ctrl+alt+c"` | 打开设置窗口的三连组合键 |
| `offset_x` / `offset_y` | `20` / `20` | 相对鼠标位置的偏移（-100 ~ +100） |
| `display_mode` | `"trigger"` | 显示方式：trigger（触发显示）/ sticky（保持显示）/ always（常显） |
| `dwell_ms` | `1000` | 触发后显示时长，仅 trigger 模式生效（取值 300 / 500 / 1000 / 2000 / 4000 毫秒，越界值会就近吸附到档位） |
| `clamp_to_screen` | `true` | 屏幕边界钳制 |
| `show_caption` | `false` | 显示偏移标注 `x +n y +n` |
| `show_marker` | `true` | 显示指向鼠标的三角标 |
| `show_debug` | `false` | 在浮窗底部显示输入法识别诊断行（排查用） |
| `click_through` | `true` | 鼠标穿透 |
| `lang_override` | `"auto"` | 语言识别：auto / pin / wubi / en |
| `scale` | `1.0` | 缩放（0.6 ~ 2.0） |
| `alpha` | `0.95` | 不透明度（0.30 ~ 1.0） |
| `ui_language` | `"zh"` | 设置界面语言：zh / en |

## 可视化 - 悬浮窗渲染与跟随机制大致思路备忘

**屏幕参考系名词 :** 鼠标坐标，偏移量，目标坐标，虚拟屏幕矩形
**窗口参考系名词 :** 画布尺寸，徽标宽度，底板圆角半径

- **① 初始化:** 主窗口 `Tk()` 只 `withdraw()` 不显示，仅作为事件源；悬浮窗是 `Toplevel` + `overrideredirect(True)`，创建后同样先隐藏，避免启动瞬间闪一个空白方框。

- **② 渲染:** 采用"全量重绘"（`canvas.delete('all')` 后重画）而非局部更新：先按内容算出画布宽高，再画圆角底板、偏移标注、旋转三角标、两个圆角徽标与文字，最后用 `geometry()` 同步窗口尺寸。Tk 画布不做抗锯齿，所以透明色键抠底不会出现彩边。

- **③ 跟随:** 每帧取一次鼠标坐标，目标坐标 = 鼠标 + 偏移，钳制到虚拟屏幕内，再 `geometry('WxH+x+y')` 更新；只有坐标变化时才真正调用，减少无谓的窗口重定位。

- **④ 透明与穿透:** 窗口底色与画布底色都设成透明色键（`#FF00FE`），再用 `-transparentcolor` 抠掉；随后通过 `SetWindowLongPtr` 追加 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW | WS_EX_LAYERED`，让浮窗不抢焦点、鼠标穿透、不出现在 Alt+Tab 列表里。

- **⑤ 弹出与隐藏:** 触发时记录 `hide_at = now + dwell_ms`，每帧比对时间；"常显"、"保持显示已按下"或"设置窗口打开"时不隐藏，最后一种兼作实时预览。
